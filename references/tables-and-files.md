# 表格与文件组织

适用于广东技术师范大学。用一份费用账本生成查阅视图；字段和工作表按实际复杂度取舍，不为每个字段建独立页。

## 表格内容和阅读顺序

每个赛事一份主汇总。多人复杂材料可使用“费用汇总 → 费用与凭证 → 个人对应 → 原始票据”；简单或单人材料可将汇总、明细和付款图放在同页。保留用户参考表的简单风格，不机械增加工作表。

| 内容 | 需要表达的事实 |
| --- | --- |
| 汇总 | 出发、返程、住宿；对应人员；票面合计、附加项目、优惠、退款、商户净支付、拟申报或待确认、差额说明 |
| 费用明细 | 事项名称、受益人／乘车人／入住人、期间或路线、付款人、票面项目、完整发票号、金额、拟申报、状态、原票相对路径 |
| 支付对应 | 对商户付款／内部结算／退款、交易标识、日期、收付款人、金额、退款关联、覆盖哪些费用、截图路径 |
| 个人对应 | 实名与必要的昵称对照、本人各段票据、关联商户订单、合并结算、共享住宿、唯一计账位置 |
| 差异缺项 | 问题、已知金额、缺失依据、当前处理、来源；与当前完整资料集一致 |

关系复杂时在内部使用唯一费用键、支付键连接多对多关系；查阅页显示“张三出发车票”“六人共同出发付款”等中文材料名称，不要求审核人先理解编号体系。共享支付的多次引用不增加付款笔数。

汇总顶部给出赛事、人员和主要金额，下面按出发、返程、住宿排列。截图与对应文字和金额靠近，标实名及用途，避免另放到很远或只有图片无文字。黑色文字、普通网格、必要的加粗和空行即可，不加装饰色块、图标、仪表盘或多余封面。

金额为数值单元格，两位小数；小计总计用公式。票号和交易号作文本，必要时加“票号：”前缀保留全部数字。缺失金额留空并说明，未分摊共享费用不伪造完整个人总额。截图不能替代可编辑金额。

分别标明票面总额、商户净支出、个人结算、拟申报及待审核；范围重叠的总计不再相加。退款单独登记或在原支付行扣除，选择一种，不重复扣；优惠用正金额并在公式减去，原表负值先确认口径。

## 推荐目录

```text
报销材料/
  00_先看这里.txt
  01_待确认事项.txt                  有待确认事项时才创建
  01_赛事名称（城市或阶段）/
    00_费用汇总.xlsx
    01_共同购票/                     单人可直接叫“车票”
      01_出发/                      各人原票、订单、商户付款、优惠
      02_返程/                      各人原票、订单、商户付款、退款
      03_往返合并转账（仅结算）/       合并个人转账、群收款明细
    02_住宿/
      张三+李四/                    实际入住人；发票和付款放一起
      王五/
    03_送物资支援（待审核）/          仅有该业务时创建
    04_按个人查找/                   需要个人视图时创建
      张三/                         个人票据及共享说明
```

顺序号只用于排序；不用城市拼音缩写。赛事根目录不必列全体队员使路径过长，完整名单写在汇总中。多赛事、城市、阶段分别归档；共享订单覆盖多队时保留共享范围，不任意全划给一队。

同一费用的原票与商户付款放在能直接对应的目录中；出发附加服务费及优惠放出发目录，返程同理。信息服务费项目与资格仍单独列示，不因文件同目录就混成铁路票价。个人合并转账放“仅结算”目录，避免误当成新增支出。

按个人视图是查阅副本或稳定索引，说明共用票据、商户付款及唯一计账位置。共享房费只计一次，未确认分摊时不写成个人费用。需要提交压缩包时不要依赖本机快捷方式。少量单人材料不必造第二套目录。

旧版、历史说明确有追溯需要时放末尾并标“历史参考”；不用的工作底稿不混进日常查阅区，不靠空文件夹凑结构。

## 中文命名

下例姓名、日期和金额均为虚构示例。优先保留业务上最有辨识度的信息，日期、票号尾号仅在同名冲突或多次行程时补充；不要拼入全部字段造成过长路径。

```text
出发车票_张三_广州南至厦门北_230.00元.pdf
返程车票_张三_厦门北至广州南_227.00元.pdf
出发信息服务费发票_六人共同_120.00元.pdf
出发付款记录_六人共同_1490.00元.jpg
出发优惠证明_六人共同_10.00元.jpg
住宿发票_张三+李四_246.00元.pdf
住宿付款记录_张三+李四_246.26元.jpg
往返合并转账_张三转王五_500.00元.jpg
群收款记录_王五发起_五人支付明细.jpg
```

发票的 JPG 副本写“车票预览／发票预览”，商户支付截图写“付款记录”，同学间的截图写“合并转账／内部结算”，便于区分。多人共享文件可用“六人共同”等短语，但汇总必须列出完整适用名单。不以“周”“郑”代替完整实名，不用“房1、房2”替代入住人。

同一人同路线同金额的多张票，用日期、路段或票号尾号区分，不覆盖已有文件。改名只改副本文件名，不改原票或交易截图内容；同步更新所有表格、索引和说明。采用包内相对路径，不依赖本机微信临时目录。

## 去重和交付复核

- 用哈希查相同文件，用票号及业务事实识别重开、不同格式与预览副本；同一交易的多张截图只增加证据。
- 文件名的（1）（2）和修改时间只是线索；对比数值、备注、嵌入图片和覆盖范围选底稿。旧表写“未提供”的材料可能已在新包补齐。
- 修改现有材料包前留可恢复备份；用户要求“复制一份”时操作新副本，保留原目录。
- 校验包内路径均能解析、文件名无冲突、原票可打开、金额和公式无误；改名时复核 PDF 和图片哈希不变。
- Excel 改名和布局调整保留无关金额、公式、完整票号、图片与锚点；渲染检查受影响页面，避免文字截断、科学计数法及图片遮挡。
- 仅交付可用材料、汇总和简短说明；脚本、渲染图、调试文件、临时校验输出留在工作目录。
