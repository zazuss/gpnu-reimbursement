# 广东技术师范大学报销整理 skill

适用于广东技术师范大学的比赛差旅与物品采购报销材料整理。处理多人代购、合住、优惠退款、合并结算和特殊行程，输出简洁的 Excel 汇总与易查阅的中文材料目录。

## 分享给 agent

将下面这段话发给 agent，并附上需要整理的报销资料：

> 请读取这个仓库 https://github.com/zazuss/gpnu-reimbursement 的 SKILL.md 及其引用资料，按照里面的流程和表格风格，帮我整理广东技术师范大学的报销材料。

## 使用

技能入口：[SKILL.md](SKILL.md)。将本仓库克隆或下载为 `gpnu-reimbursement` 文件夹，放进所用工具的技能目录。在 Codex 中可放到用户目录的 `.codex/skills/` 下，并在新会话中使用：

> 使用 $gpnu-reimbursement 检查这些广东技术师范大学报销材料，按赛事整理，核对票面、实际付款、优惠和个人结算，列出待确认事项。表格保持简单，文件用直观中文命名。

核心 Markdown 流程可供其他能读取文件的 agent 参考；`agents/openai.yaml` 是 Codex 的界面元数据。不同工具的发现方式及文档处理能力需分别适配。

## 包含内容

- 差旅与采购流程，以及票款、优惠和共享费用核对方法。
- 表格、中文命名、材料位置和交付复核规范。
- 学校住宿和交通标准摘要、三份来源 PDF。
- 虚构的匿名核对示例。

学校标准按随附资料整理，记录日期为2026-10-15；新业务应核对适用版本。本仓库不包含真实聊天、个人发票、支付截图或个人报销账本。它用于整理和指导，正式报销以适用学校制度与财务审核为准。
